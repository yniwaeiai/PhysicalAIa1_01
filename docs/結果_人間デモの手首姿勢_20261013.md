## 読み（事実と、計画への影響）
1. **手首を大きく傾けているのは中段引き出しだけ（約 62°、方位は全デモで同じ）。** 下段（28°）と電子レンジ（20°）は中程度。
2. **上段引き出し・皿押し・つまみは人間も真下向き（tilt 5° 以下）。** 計画書の「3 動作は傾けないと実行できない」は、この 3 つには当てはまらない。expert が失敗した原因は傾きでなく別（取っ手の検出・棚との干渉）の可能性が高く、**未検証**。
3. 引き出しは**グリッパを閉じずに開いた指を引っかけて引く**。expert の「掴んで引く」とは別の動作で、新しいプリミティブが要る。
4. 電子レンジのタスクは「マグを入れて**閉める**」で、開ける動作ではない（扉は −1.87 rad の開から 0 へ）。計画の「扉を開ける」は「閉める」に直す。

## 限界
- back 窓（閉じる・戻す動き）は検出条件を満たさず 0 件。K4 の「引き出しを閉める」押しは未解析。
- 方位は固定物（棚・電子レンジ）の座標系。符号の意味（手前に倒すのか奥か）は未確認で、次に確認する。

## 追記: 中段引き出しの傾きの向き（demo_0 で確認、世界座標）
- 棚の座標系は世界を z 軸まわりに 180° 回したもの（x_棚 = −x_世界、y_棚 = −y_世界）。引き出しは**世界 +y 方向**へ開く（関節 q は 0 → −0.149、手先の y は −0.131 → +0.015）。
- 引き始め（step 105）: ツール z 軸 = (−0.06, −0.85, −0.53)（tilt 58°）。引き終わり（step 128）: (−0.06, −0.96, −0.27)（tilt 74°）。
  **指先は引く向きと逆（世界 −y = 棚の内側）をほぼ水平に向く。** 指の開閉軸（ツール y 軸）は世界 +x、つまり取っ手の棒（x 方向）に沿う。
- 読み: 手首を 60〜75° 倒し、指先を水平に棚の内側へ向けて取っ手の裏へ回し込み、引く向きへ手を戻す。手の本体と前腕は取っ手より手前（+y 側）・上にあり、前板の上の天板に当たらない。
- 取っ手の geom 名に `handle` を含むものは無い（`wooden_cabinet_1_g21`〜`g31` の無名 geom）。expert の目標点は、引き出しの body 位置と、デモの接触点（手先の中央値）から決める。

## 追記2: 中段引き出し expert v1（10/13、`kadai/scripts/run_drawer_hook.py`）
- 人間デモの 8 キーポーズ（棚座標、`kadai/state/hook_keyposes_middle.json`）を、実行時の棚の位置・向きで世界座標に直して、手先の位置と全姿勢を追従する（接近 → 内側へ → 引っかけ → 引く）。グリッパは開いたまま。
- **人間デモの接触の実体: 指のパッドが取っ手の棒の上面の奥側の縁に乗り、約 200 N で押しつけて引く**（`g29`、`g22/g24` は前板）。手首を倒して指先を水平近くにするのは、手の本体を前板・天板から離すため。
- 初回は 0/4（引っかけ位置が棒の上 1.5 cm・外側 2.5 cm）。キーポーズの高さを 1.2 cm 以上下げると 4/4（`dz` ∈ {−0.012, −0.018, −0.024} × 奥行き補正 {0, 1.5, 3 cm} で、`dz=0` だけが全滅）。**既定は dz = −0.018（成功域の中央）。**
- **LIBERO-Plus の init 50 行で 成功 ∧ 対象外 ≤ 1 mm = 50/50、ステップ数は人間デモ中央値 136.5 に対し expert 約 165。** 成功の線（≥70%）を中段引き出しで達成。
- 留意: 評価した 50 初期状態は init 行のみ（摂動なし）。ロボットの初期姿勢・配置の摂動に対する頑健性は未測定。

## 追記3: 中段引き出し expert v2（摂動試験と高速化）
- 摂動試験（12 初期状態、ロボット初期関節 ±0.1 rad、棚の位置 ±3 cm・向き ±5°、強い版は ±0.2 rad・±6 cm・±10°）で **すべて 12/12 成功 ∧ 対象外 0 mm**。操作チェック: 強い摂動で T が 165〜173 にばらつく（摂動は効いている）。
- 高速化: `H_IN` の許容を 0.8 cm / 8° → 1.5 cm / 12° に緩めると、全 seed で `timeout`（70 step 粘る）だった待ちが無くなり、**ステップ数の中央値 166 → 111.5（人間デモ 136.5）、成功は 12/12 のまま。** 既定値に採用。

## 訂正: KITCHEN_SCENE4 の下段引き出しは最初から開いている
人間デモの関節は始値 q = −0.14〜−0.16（開）→ 終値 0.002（閉）。したがって表の「下段引き出し（開ける）28°」は**閉める押しの区間**だった（窓の定義は変位の大きさなので向きを区別していなかった）。電子レンジ（開いた扉を閉める）と同様、K4 も「傾けて押して閉める」動作で、中段引き出し（引っかけて開ける）とは別系統。計画書の説明を訂正した。
