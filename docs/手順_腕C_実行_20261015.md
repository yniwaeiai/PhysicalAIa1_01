## 2. 変換 + 学習 + merge（段 2）
`nohup bash kadai/scripts/pod_run_contrast_train.sh > /workspace/logs/contrast_train.out 2>&1 &`（rollout 中に起動しておいてよい。フラグ待ちで止まっている）
1. `contrast_ROLLOUT_DONE` を待つ → **builder（CPU、約 10〜20 分、GO 不要）**。`--images frames --frames-root data/contrast/frames_c --per-window 2 --holdout-seeds 8080-8099 --check`。表（窓数・本数・フレーム・失敗の内訳・打ち切り・stale 率（frames では 0%）・教師比）が `/workspace/logs/contrast_train.log` と `data/contrast/ds_c1/summary.json` に出る。**確認**: (i) `[check] OK`、(ii) ロールアウトのフレーム ≤ 教師 79,854（超えたら `PER_WINDOW=1`）、(iii) 各タスクに混在窓、(iv) rep 間の act_exec が別標本、(v) frames と trace の整合の assert が全 ep で通る（frames の ee[k] = trace の ee[k-1]、差 < 1e-6。推論時画像が画素一致）。→ `contrast_BUILD_DONE`。t=0 は落とす（frames に quat・グリッパ状態が無い）ので各 ep は t=1 始まり（attrs `t_offset=1`）
2. **親が `/workspace/logs/contrast_TRAIN_GO` を置くまで学習は始まらない**。
3. 学習（`kadai_c1`）: **2,400 step の 1 本のみ**（v1・v3 と同一条件: rank 16 / α 32 / attn-mlp / lr 1e-4 / warmup 200 / batch 16 / seed 0 / `--n-test-tasks 0` / workers 16 / eval・save 400、snapshot なし）。ログ `/workspace/logs/contrast_train_kadai_c1.log`。**所要 約 3.5 h**。確認: 学習パラメータ 35.24M、loss が v1 と同程度（`kadai/state/train_curves_v1_v2_20261016.md` と並べる）。
4. merge（`scripts/merge_lora.py`、数分。最終の `lora.pt` から）→ `data/contrast/policy/c1_s2400/`。→ `contrast_TRAIN_DONE`
- **3,600 step は、前提試験が境界（第 1 チャンク AUROC 0.55〜0.65）のときだけ別 run として追加**: `EXP=kadai_c1_3600 STEPS=3600 MERGE_AT=3600 bash kadai/scripts/pod_run_contrast_train.sh`（GO が要る。ただし cosine は 3,600 で落ち切る別条件）。policy は `c1_s3600`。

## 7. 注意（実装の判断）
- 画像は rollout 時の毎 step 保存（`--save-frames --frame-every 1`）から取る。trace の推論時画像だけの旧経路は `--images stale`（非既定）。frames の保存名に rep が無いため rep 別プロセス・別ディレクトリ。t=0 は state が作れないので落とす。
- builder の frames 検査は手元では A' の trace から作った**模擬 frames**（画像は trace の推論時画像の使い回し）で通した。実 frames での検査は Pod の煙検査（§1）が初回。
- 評価は `eval_kadai_closedloop_cfg.py`（環境変数 `KADAI_CFG_W`）。元の eval は未変更。
