## 測定（事前固定）

## 操作チェック
- 件数: drawer 320 = S 292 + F 28、k4 271 = S 259 + F 12、k6 267 = S 259 + F 8。報告どおり一致。
- 位置の整列: demo の state[0] xyz は trace ee[t] ではなく **ee[t-1]**（trace の ee[i] は行動 i 実行後）と一致する。照合は 中央 0.79 mm、p90 1.11 mm、最大 1.74 mm（許容 2 mm 内）。demo の行動 0 は trace の行動 t に対応し、b の窓 t..t+9 はこれで正しい。
- 行動規約: demo も trace も [-1,1] の OSC_POSE delta で、|action| の最大の中央値はどちらも 1.000。同じ尺度。（`act_raw` を使っても cos の中央値は同一。）
- trace は seed ごとに 1 本（`{task}_s{seed}_r0.npz`、300 本）。

## 判定
線（事前固定）: drawer S 起源で cos<0.5 の割合が 30% 以上なら (c) 支持、10% 未満なら反証、その間は保留。
数値: drawer S の cos<0.5 は 0.192（56/292）。中央値 cos は 0.980。
**判定: 保留**（10% と 30% の間）。

読み取り（判定の外の記述的所見）:
- drawer の不一致は t≥35 に集中する。t≤30 では cos<0.5 が 0 件（最小でも高 cos）、t=35 で 56%、t=40 で 95%。不一致 56 件のほぼ全部が t=35・40。つまり「再接近が方策自身の行動と食い違う」現象は、分岐が遅い（v1 がすでに次の段階へ進んでいる）ときに限られ、大半の demo は v1 と同じ向きに動き出す。
- k6 は全体で cos<0.5 が 50%、t≥20 でほぼ全件の反転。k4 は drawer と同程度（22%）で、同じく t≥35 に集中。
- F 起源の n は小さく（8〜28）、傾向は参考のみ。
- 本測定は demo の冒頭 10 行動と v1 の同区間のみを比べる。「同状態での二つの行動モード」の存在そのものを示す下限であり、退行の主因かは別に確かめる必要がある（例: t≥35 を除いた学習との比較）。退行が「無摂動で最大」という既知の所見とは、この不一致が摂動と無関係に t 側で決まる点で整合も矛盾もしない（本測定は水準別に分けていない）。
